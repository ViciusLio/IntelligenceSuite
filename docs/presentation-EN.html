06  —  DocIntelligence
Every document.
Every format.
Never crashes.
Best-effort parsing at 3 levels — always returns at least one chunk, regardless of how complex or broken the source file is.
"What are the rollback steps for production deploy?"
→ Found in deploy_procedure.pdf · Section 4 · page 3
📕

PDF — 3-level parsing

Level 1: pdfplumber with y-coordinate font-size detection for headings.
Level 2: OCR via pytesseract for scanned pages.
Level 3: raw binary regex fallback — never fails.

📘

DOCX — heading-aware

Reads Heading 1/2/3 styles for structured sections. Tables extracted as Markdown. Sections with empty body are preserved.

📗

XLSX · TXT · Markdown

Per-sheet chunking for Excel with markdown table preview. Plain text and Markdown with heading-based splitting.

09  —  Quickstart
Up and running in 5 minutes
# 1. Install
$ git clone github.com/ViciusLio/IntelligenceSuite
$ pip install -e ".[dev,pdf,docx,xlsx]"
$ cp .env.example .env

# 2. Index your codebase
$ python -m CodeIntelligence.parse_repo ./src
$ python -m CodeIntelligence.embed_chunks

# 3. Start the server
$ python -m CodeIntelligence.rag_server
▶ Listening on http://localhost:8080 ✓
Query the REST API
# Ask a code question
$ curl -X POST localhost:8080/api/v1/query \
  -H "Content-Type: application/json" \
  -d '{"question":"Where is auth handled?"}'

# Ask a doc question
$ python -m DocIntelligence.ingest_docs ./docs
$ python -m DocIntelligence.embed_docs
$ python -m DocIntelligence.doc_server

# Start onboarding session
$ python -m MentorIntelligence.mentor_server
▶ All systems up ✓
