Escalation policy

Se la confidenza locale e' sotto soglia o la query e' troppo complessa, scala automaticamente all'API Claude. Completamente configurabile via ESCALATION_THRESHOLD.

Il retriever aggiunge +0.1 per termine trovato (cap a +0.3) sopra al punteggio semantico. Migliora il recall per identificatori esatti come nomi di funzione o codici di errore.

09  —  Quickstart
Operativo in 5 minuti
# 1. Installa
$ git clone github.com/ViciusLio/IntelligenceSuite
$ pip install -e ".[dev,pdf,docx,xlsx]"
$ cp .env.example .env

# 2. Indicizza il codebase
$ python -m CodeIntelligence.parse_repo ./src
$ python -m CodeIntelligence.embed_chunks

# 3. Avvia il server
$ python -m CodeIntelligence.rag_server
▶ In ascolto su http://localhost:8080 ✓
Interroga la REST API
# Domanda sul codice
$ curl -X POST localhost:8080/api/v1/query \
  -H "Content-Type: application/json" \
  -d '{"question":"Dove e gestita l auth?"}'

# Domanda sui documenti
$ python -m DocIntelligence.ingest_docs ./docs
$ python -m DocIntelligence.embed_docs
$ python -m DocIntelligence.doc_server

# Sessione di onboarding
$ python -m MentorIntelligence.mentor_server
▶ Tutti i sistemi attivi ✓
